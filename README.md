# research-tools-week1

Data Security and Privacy Protection Experiment 1.

This repository records the basic use of Git, GitHub, Codex, CC Switch and LaTeX.

## Directory structure

- `code/`: experiment programs
- `result/`: program outputs
- `report/`: experiment report

## Program

`code/text_stats.py` reads an English text file and counts the frequency of each word.

## Usage

```powershell
python code/text_stats.py sample.txt
```


## Result

The program was tested with `sample.txt`.

```text
Word frequency:
code            3
git             2
helps           2
manage          1
records         1
```
